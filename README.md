# PeriodicTableConsoleApp


# Data Sources

This project incorporates and/or derives data from the following sources:

- **PubChem (NIH/NLM)** — Periodic-table and chemical element data.
- **NuDat / NNDC (Brookhaven National Laboratory)** — Nuclear structure,
  isotope, decay, and related evaluated nuclear data.
- **FENDL / International Atomic Energy Agency (IAEA)** — Evaluated nuclear
  reaction data used for neutron-, proton-, and deuteron-induced reactions.

The original data remains attributable to its respective providers.
This project transforms these sources into a unified data structure for
programmatic use.

See each provider's respective terms, documentation, and data policies for
additional information.**
